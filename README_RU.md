# VidoAI — backend для реальной генерации коротких AI-видеоклипов

## Что уже умеет этот backend
- `POST /api/generate`: принимает текст, необязательную фотографию и стиль.
- Если есть фотография — вызывает image-to-video; иначе — text-to-video.
- Сохраняет полученный MP4 в `outputs/` и возвращает URL.
- API-токен хранится только в `.env` на сервере.

## Честное ограничение
Один вызов модели создаёт короткий клип (длительность зависит от модели), НЕ готовое видео на 3 минуты или 1 час. Длинный ролик нужно собирать из множества сцен: сценарий → список сцен → генерация каждой сцены → озвучка → субтитры → склейка через FFmpeg. Это требует дополнительных запросов и может стоить денег. Начинайте с одного клипа, прежде чем делать длинные проекты.

## Шаг 1. Создайте API-токен
1. Откройте https://huggingface.co/settings/tokens
2. Создайте токен с разрешением Inference Providers.
3. Проверьте доступность модели и провайдера. Условия бесплатных кредитов и модели могут меняться.

По официальной документации Hugging Face, бесплатному аккаунту предоставляются небольшие месячные кредиты для тестирования (в документации сейчас указано $0.10, сумма может измениться). Этого обычно недостаточно для большого фильма. Не включайте платное списание, если не готовы к расходам.

## Шаг 2. Установка на компьютер
Установите Python 3.11 или новее. В папке проекта:

```bash
python -m venv .venv
```

Windows:
```powershell
.venv\\Scripts\\activate
```

Linux/macOS/Termux:
```bash
source .venv/bin/activate
```

Установите зависимости:
```bash
pip install -r requirements.txt
```

Создайте файл `.env` копированием `.env.example` и вставьте свой токен в `HF_TOKEN`.

## Шаг 3. Запустите API
```bash
uvicorn main:app --host 127.0.0.1 --port 8000
```
Откройте http://127.0.0.1:8000/docs — там можно проверить API. Для доступности с других устройств в локальной сети можно использовать `--host 0.0.0.0`, но не публикуйте backend без защиты.

## Шаг 4. Проверка
В Swagger (`/docs`) откройте `POST /api/generate`, введите `prompt`, при желании загрузите `photo`, затем нажмите Execute. Если генерация успешна, откройте возвращённый `video_url`.

## Шаг 5. Подключите фронтенд
`frontend-integration.js` показывает код, который отправляет форму в backend и отображает результат. Для локального теста фронтенд должен работать на адресе из `CORS_ORIGINS`.

## Безопасность перед публикацией
- Не загружайте `.env` в GitHub.
- Не вставляйте HF_TOKEN в `index.html` или `app.js`.
- Ограничьте запросы на пользователя, размер файлов и число задач.
- Добавьте авторизацию, квоты, очередь задач и очистку старых MP4.
- В production поставьте HTTPS и используйте домен backend в CORS_ORIGINS.
